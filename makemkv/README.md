# MakeMKV

Miscellaneous MakeMKV notes.

## Multiple identical main features

If there are multiple main features with identical segments but different tracks, the difference is most likely due to regional subtitle spellings. 

For example:
```
FPL_MainFeature_UR_A
FPL_MainFeature_UR_B
```

In this case, `A` has Americanized words and B has British ones (e.g. "realize" vs "realise").

This has been [documented for several titles](https://forum.makemkv.com/forum/viewtopic.php?style=11&t=26800), such as The Guns of Navarone (1961) and Underworld (2003) - both Sony releases.
